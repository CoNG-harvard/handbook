# VLA Pipeline

A tabletop platform with **two xArm 7 robots**, grippers, **two wrist cameras**, **three scene cameras**, and Quest headsets for operator control. It uses the workstation shared with Self Improvement Learning.

**Your goal:** assemble and identify both rigs, arrange clear camera views, and have an operator check the connections and stop controls.
